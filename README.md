# Console Messenger

Native iOS client for Console.

## Client stack
- Swift
- SwiftUI
- CryptoKit
- Keychain
- URLSessionWebSocketTask
- iOS 17+
- Bundle ID: `com.iumrah.beta`

## Server
Cloudflare Workers + Durable Objects remain a separate backend layer.

## Build
The Xcode project is generated from `project.yml` using XcodeGen on a GitHub Actions macOS runner.
